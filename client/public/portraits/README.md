# Retrato de exemplo

`elara-example.png`: personagem fictícia Elara Sombravil, gerada com a ferramenta ImageGen em 9 de setembro de 2026 para demonstrar o token de personagem no Storybook. Retrato pintado, fundo frio e roupa discreta. Não representa uma pessoa real e não é atribuído automaticamente a personagens do produto.

O PNG original é preservado; a apresentação circular é feita pelo componente Avatar.
