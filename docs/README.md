# Documentação

Comece pelo [`README.md`](../README.md) (setup) e pelo
[`CONTRIBUTING.md`](../CONTRIBUTING.md) (como contribuir). O catálogo de
componentes é o Storybook (`npm run storybook`).

## Referência

- [`architecture.md`](architecture.md): workspaces, fluxos (auth, RBAC,
  rolagem e feed ao vivo), princípios, decisões registradas e onde mexer para
  cada tipo de mudança.
- [`roadmap.md`](roadmap.md): o que está entregue, as próximas fases e as
  questões em aberto.
- [`design-system.md`](design-system.md): tokens, temas, componentes e as
  garantias verificadas por `npm run test:design`, com o histórico de
  acabamento por data.
- [`pullfrog.md`](pullfrog.md): review e correção automática de PRs, cadeia
  de modelos, política de auto-merge, setup do App e checagens visuais.

## Histórico

- [`history/`](history/): o raciocínio original de cada etapa (proposta,
  design, requisitos e tarefas), preservado como registro. Não é processo
  obrigatório para mudanças novas.
- [`ui-ux-etapas-0-1.md`](ui-ux-etapas-0-1.md): auditoria de UI/UX das etapas
  0 e 1 (setembro de 2026) e o que ficou fora de escopo.
- [`storybook-review.md`](storybook-review.md): revisão que transformou o
  Storybook de uma story única no catálogo atual.
- [`guia-dnd-5e-online-gratuito-discord.md`](guia-dnd-5e-online-gratuito-discord.md):
  estudo anterior ao produto, preservado como referência.
